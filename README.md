# GNZ Player

Reproductor flotante para ver los partidos que abres desde la página, en una ventana siempre visible y sin anuncios.

## Descargar

| Sistema | Descarga |
|---|---|
| **Mac** (macOS 13 o más nuevo, Apple Silicon e Intel) | [**GNZPlayer.pkg**](https://github.com/gnz479/-gnzplayer/releases/latest/download/GNZPlayer.pkg) |
| **Windows** 10 / 11 (64 bits) | [**GNZPlayer-Setup.exe**](https://github.com/gnz479/-gnzplayer/releases/latest/download/GNZPlayer-Setup.exe) |
| Windows, versión portátil (sin instalar) | [GNZPlayer-portable.zip](https://github.com/gnz479/-gnzplayer/releases/latest/download/GNZPlayer-portable.zip) |

## Instalar

**Mac**
1. Abre `GNZPlayer.pkg`. Si macOS dice que no puede verificar al desarrollador: clic derecho sobre el
   archivo → **Abrir**, o **Configuración del Sistema → Privacidad y seguridad → Abrir de todos modos**.
2. Sigue el asistente. Al terminar, GNZ Player se abre solo y ya puedes volver a la página y darle a **Ver**.

**Windows**
1. Abre `GNZPlayer-Setup.exe`. Si aparece **"Windows protegió tu PC"**: **Más información → Ejecutar de todas formas**.
2. Sigue el asistente (no pide permisos de administrador). Al terminar, vuelve a la página y dale a **Ver**.

La primera vez, el navegador pregunta **"¿Abrir GNZ Player?"**: marca **"Permitir siempre"** para que no vuelva a preguntar.
